# Gym Log — https://alhaiqi.github.io/gym/

Upper-body hypertrophy tracker (bulking, A/B rotation, 3–4 days/week): workout mode with set steppers and rest timer, adaptive weekly plan, same-muscle exercise swaps with technique tips and pictures, history and progress, export/import. Installable and works offline.

## Groceries — https://alhaiqi.github.io/gym/groceries/

Weekly shopping list built from the meal plan (daily amounts × days). Items in the same group replace each other: mark one "Not available" and its share moves to the next item (tomatoes → cucumbers → carrots…). Edit amounts and the mix in **My plan**, add extra items in **Add item**, share the list as text.

## Chrome extension

`extension/` → `chrome://extensions` → Developer mode → **Load unpacked**.
**Alt+Shift+G** opens Gym Log, **Alt+Shift+F** opens Groceries (change at `chrome://extensions/shortcuts`).

Data stays in each browser (localStorage). Exercise pictures: free-exercise-db (public domain).
