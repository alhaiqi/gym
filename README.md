# Gym Log — https://alhaiqi.github.io/gym/

Upper-body hypertrophy tracker (bulking, A/B rotation, 3–4 days/week): per-set logging, rest timer, adaptive weekly plan, same-muscle exercise swaps, history and progress, export/import. Installable (Add to Home Screen) and works offline. Data stays in each browser.

`extension/`: Chrome extension that opens the app with the toolbar button or **Alt+Shift+G** (chrome://extensions → Developer mode → Load unpacked).
